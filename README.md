# Loan Origination System for High Net Worth Customers

This repository contains the design and implementation of a Loan Origination System (LOS) for high net worth customers of a financial institution. The system is designed to handle complex loan applications with various types of collateral including portfolios, real estate, and high-value artifacts.

## System Features

1. **Advisor-Operated Interface**: Designed for financial advisors to manage loan applications for high net worth clients
2. **Loan Application Validation**: Comprehensive validation of loan applications against business rules
3. **KYC and Collateral Valuation**: Advanced KYC processes and valuation of complex collateral types
4. **Workflow Override Management**: Ability to generate and process overrides when rules fail
5. **Document Generation**: Automated generation of loan documents with digital signature capabilities
6. **Scalable Architecture**: Designed for high availability and performance
7. **Audit Capabilities**: Complete audit trail for all system activities
8. **Domain-Driven Design**: Implemented using domain-driven design principles

## Repository Structure

- `/docs/design`: Contains component, high-level, and low-level design documents
- `/docs/prompts`: Contains records of design discussions
- `/src`: Source code for the implementation
