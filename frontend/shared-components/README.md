# Shared Components

This package contains shared UI components for the Avalon loan origination system.

## Components

- StatusChip - Display status indicators with appropriate colors
- Header - Application header with navigation
- Footer - Application footer
- PageHeader - Page title and action components
- DataCard - Card component for displaying data

## Usage

Import components directly:

```tsx
import { StatusChip, Header, Footer } from 'shared-components';
```
